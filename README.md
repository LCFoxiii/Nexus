# Nexus
Nexus is an open source discord bot, complete with a text-based MMORPG game.

Nexus takes a huge inspiration from my friend's facebook AI chatbot, back when Meta AI didn't exist yet. To this day, I still don't know how he did that.

The nexus folder is a collection of features that I can faintly remember from the bot, alongside new features.

## Folders
Just in case you don't know.
- [**core**][folder_core], A folder that basically sets up everything
- [**general_helpers**][folder_gereral_helpers], A folder where general-purpose helper functions are stored.
- [**nexus**][folder_nexus], The main Discord bot folder.
- [**slimequest**][folder_slimequest], The main text-based MMORPG game folder
